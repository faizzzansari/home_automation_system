# 🏠 Home Automation System

An IoT-based Home Automation System that allows users to control connected home appliances through a Flutter mobile application. The system uses an **ESP32 microcontroller** for hardware control and communication with the mobile application.

## 📌 Project Overview

This project combines **IoT hardware, embedded programming, and mobile application development** to create a smart home automation solution.

The system consists of two main components:

- **ESP32 Code** – Handles appliance/device control and hardware operations.
- **Flutter Application** – Provides a mobile interface for users to interact with and control connected devices.
